No external API integration: Phase 1 reads a static XMLTV document, either with one plain HTTP(S) GET of a user-supplied URL or from a local file, and parses it as a file format. There is no remote API surface (no endpoints, verbs, auth flows or SDK) to cover. The detector fired on the phrase "API keys", which refers to tokens some EPG providers embed in feed URLs. Home Assistant core interfaces (config entries, coordinator, calendar platform) are the host framework, not an integrated external service.
