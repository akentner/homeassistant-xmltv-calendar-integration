## Phase Goal

**As a** Home Assistant user, **I want to** add an XMLTV source (URL or local file) in the HA UI and attach calendars filtered by channel and include/exclude regex, **so that** I see exactly the matching programmes as correctly timed calendar events that drive my calendar-trigger automations.

<objective>
Publish the repository and observe DST-01 and DST-02 live: CI and Validate green on GitHub, and HACS accepting the repo as a custom repository.

Pushes are the user's job (CLAUDE.md), so the plan is local gate, then the human push, then automated confirmation. This plan adds no code layer, so there is no tracer slice to lead with: the publish pipeline can only be exercised end to end after the push, and Task 1 runs every gate CI will run so the push is not the first time anything is checked.

Output: a public GitHub repository with green CI and Validate runs, plus a HACS check queued for UAT.
</objective>
