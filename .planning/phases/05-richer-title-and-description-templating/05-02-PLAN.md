Output: six translated error keys in English and German, the reworded help texts, the `variables` placeholder, `validate_template` with a trial render, and flow tests for every reason.
</objective>

|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07 | Tampering | flow accepts a template that fails at render | medium | mitigate | validate_template renders a fully populated and a sparse synthetic programme and maps any exception to template_runtime_error before the value reaches pending data or storage |
| T-05-08 | Information disclosure | exception text in the error placeholder | low | accept | the form is admin-only, the trial render uses synthetic data so no feed content can appear, and the detail is cut to 200 characters |
| T-05-09 | Denial of service | trial render runs on the event loop during form submit | low | mitigate | the compile whitelist and length caps bound a template to linear cost; two synthetic programmes render in microseconds (RESEARCH measured 5.5 microseconds per event) |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | no packages added |
