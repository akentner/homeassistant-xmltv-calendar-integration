## Phase Goal

**As a** Home Assistant user, **I want to** pinpoint specific shows with field-scoped, Unicode-safe regex plus duration and time-window filters, shape event titles and descriptions with templates, check the matches in a preview before saving, and retune any calendar instantly, **so that** each calendar shows exactly the programmes I care about, clearly titled, without re-downloading the source.

<objective>
Let the user edit an existing calendar from the HA UI. The subentry flow gets a reconfigure entry point that reuses the basic -> preview -> save path, pre-filled from the stored calendar. Saving ends via async_update_and_abort, and the in-place listener from 02-01 applies the change without touching the source or the other calendars (FLT-11, D-04, D-19). Every save now writes the full stored contract (D-06).

Purpose: FLT-11 is what makes iterative tuning practical; today a wrong filter means deleting and recreating the calendar.
Output: reconfigure support in CalendarSubentryFlow, translation, end-to-end tests.
</objective>
