## Phase Goal

**As a** Home Assistant user, **I want to** pinpoint specific shows with field-scoped, Unicode-safe regex plus duration and time-window filters, shape event titles and descriptions with templates, check the matches in a preview before saving, and retune any calendar instantly, **so that** each calendar shows exactly the programmes I care about, clearly titled, without re-downloading the source.

<objective>
TDD feature: event title and description templates (EVT-03, EVT-04). A restricted placeholder template, parsed once by string.Formatter().parse and rendered by joining literals and values, shapes the title. The default stays '{channel}: {title}'. The description is either a user template or the default description built from sub-title, episode, categories and the feed description (D-20 to D-23). Calendar entity and flow preview render through the same EventTemplates.

Purpose: titles like "Formel 1 – Qualifying (Sky Sport F1)" make calendars readable at a glance, and the default description puts the useful EPG detail into every event.
Output: render.py template engine, entity and preview wiring, pure and end-to-end tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin template text (or hand-edited storage) to the renderer | A template is user-controlled text executed for every event |
| Untrusted feed text to rendered event fields | Titles and descriptions from the feed are substituted into templates |

| T-02-12 | Information disclosure / Denial of service | compile_template / render_template (format-string attribute traversal, width bombs such as {title:>999999999}) | high | mitigate | Allow-listed field names only; any format spec, conversion, '.' or '[' is rejected; rendering joins pre-validated literals and string values and never calls the str formatting methods; stored templates are re-compiled through the same validator and fall back to the default (test_broken_stored_template_falls_back) |
| T-02-13 | Tampering | Feed text containing braces substituted into templates | medium | mitigate | Feed values are inserted as data after parsing the template; they are never parsed as a template (test: a feed title "{channel}" renders literally) |
| T-02-SC | Tampering | uv dev installs | high | mitigate | No new packages (stdlib string/re only) |
</threat_model>
