## Phase Goal

**As a** Home Assistant user, **I want to** pinpoint specific shows with field-scoped, Unicode-safe regex plus duration and time-window filters, shape event titles and descriptions with templates, check the matches in a preview before saving, and retune any calendar instantly, **so that** each calendar shows exactly the programmes I care about, clearly titled, without re-downloading the source.

<objective>
Add the preview step to the calendar subentry flow. After the form, the user sees how many programmes match from now on and the next 10 with weekday, date, time, channel and title, then chooses Save or Back (FLT-10, D-15 to D-18). The flow becomes basic -> preview (menu) -> save | back; saving only happens from the preview (D-01). Every existing test that submitted the form once is moved onto a shared helper that drives the new steps.

Purpose: the user checks the effect of regexes before committing, which is the main defence against "my calendar is empty" or "it matches everything".
Output: xmltv/preview.py (pure), the multi-step CalendarSubentryFlow, translations, the complete_calendar_flow test helper and migrated tests.
</objective>
