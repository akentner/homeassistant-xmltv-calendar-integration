## Phase Goal

**As a** Home Assistant user with XMLTV sources, **I want to** have each source cached across restarts, refreshed on my own schedule and only when the feed changed, tolerant of failures and timezone quirks, editable later, and visible when something goes wrong, **so that** every calendar stays populated at minimal network and CPU cost.

<objective>
TDD feature: per-source timezone options (SRC-10). Timestamps without offset can be declared Home Assistant local time instead of UTC (D-14), and an offset correction in minutes shifts all start and stop times of a source (D-15). The interpretation lives in the pure parser (no HA imports; the coordinator passes a tzinfo and a timedelta). Option changes reload the source and re-parse the disk cache, without a download (D-16).

Purpose: many German feeds write local times without an offset or with a wrong one; without these options every event is off by one or two hours.
Output: timeparse/parser parameters with pure tables, coordinator wiring, end-to-end tests.
</objective>
