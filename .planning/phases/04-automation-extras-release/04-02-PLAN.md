## Phase Goal

**As a** Home Assistant user with filtered XMLTV calendars, **I want to** automate around matches beyond plain calendar triggers (next-match sensor, new-match event, recent past matches, ready-made blueprint) and install a documented, bilingual, tagged release via HACS, **so that** I can act on the programmes I care about without hand-built polling automations and keep the integration up to date.

<objective>
Ship the blueprint "notify before a matching programme starts" (AUT-05, D-26..D-28): import it, pick an XMLTV calendar, a lead time and a notify entity (or own actions), and get one notification per matching programme, also when programmes overlap.

Purpose: the most common automation ("tell me 10 minutes before Formula 1 starts") without writing YAML.
Output: the blueprint file and a test module that validates it with Home Assistant's schema and runs it end to end against the integration.
</objective>
