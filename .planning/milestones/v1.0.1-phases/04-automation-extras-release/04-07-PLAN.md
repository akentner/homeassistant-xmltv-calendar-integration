## Phase Goal

**As a** Home Assistant user with filtered XMLTV calendars, **I want to** automate around matches beyond plain calendar triggers (next-match sensor, new-match event, recent past matches, ready-made blueprint) and install a documented, bilingual, tagged release via HACS, **so that** I can act on the programmes I care about without hand-built polling automations and keep the integration up to date.

<objective>
Let the user set how many days past matches stay visible, per calendar, in the calendar's advanced options (EVT-07 "configurable, up to 7", D-14, D-15), in English and German.

Purpose: 04-06 made retention work from the stored key; this plan puts it in the UI, so no user ever has to edit storage.
Output: CONF_RETENTION_DAYS, the advanced-step field, its translations, flow and in-place tests.
</objective>
