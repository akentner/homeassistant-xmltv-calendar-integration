## Phase Goal

**As a** Home Assistant user with filtered XMLTV calendars, **I want to** automate around matches beyond plain calendar triggers (next-match sensor, new-match event, recent past matches, ready-made blueprint) and install a documented, bilingual, tagged release via HACS, **so that** I can act on the programmes I care about without hand-built polling automations and keep the integration up to date.

<objective>
Give every calendar a "Next programme" timestamp sensor on the calendar's device (AUT-03, D-01..D-06). Its state is the start of the next match that has not started yet; its attributes describe that match; it moves on at the match's start time, follows feed changes and in-place calendar edits, and exists for calendars added later.

Purpose: automations and dashboards can use "when is the next Formula 1 race, on which channel" directly, without calendar.get_events templates.
Output: new sensor platform, MatchIndex.next_after, calendar helpers (device_info, signal_matches, next_match, describe_match), per-platform entity callbacks in the update listener, English and German entity strings, tests.
</objective>
