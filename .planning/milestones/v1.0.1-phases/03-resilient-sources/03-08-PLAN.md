## Phase Goal

**As a** Home Assistant user with XMLTV sources, **I want to** have each source cached across restarts, refreshed on my own schedule and only when the feed changed, tolerant of failures and timezone quirks, editable later, and visible when something goes wrong, **so that** every calendar stays populated at minimal network and CPU cost.

<objective>
Let the user edit a source's schedule and timezone settings later through the options flow (CFG-02, D-04), using the same builders as setup (D-05). Saving reloads only that source through the existing diffing listener (D-07) and re-parses the cached feed without a download (D-16). The plan closes the phase with the regression gate and the hands-on UAT walkthrough on ha-dev, including the real-feed check of ETag/Last-Modified support.

Purpose: feeds change their generation time and their timezone quirks; the user must be able to fix both without deleting and re-adding the source and all its calendars.
Output: XmltvOptionsFlow, options translations (en + de), tests/test_options_flow.py, phase gate and UAT human-check.
</objective>
