## Phase Goal

**As a** Home Assistant user with XMLTV sources, **I want to** have each source cached across restarts, refreshed on my own schedule and only when the feed changed, tolerant of failures and timezone quirks, editable later, and visible when something goes wrong, **so that** every calendar stays populated at minimal network and CPU cost.

<objective>
Add the diagnostics platform for sources (SRC-12, D-21): source type, redacted URL or path, schedule and timezone options, last success and failure, cache metadata, parse counters including skipped_malformed, and per-calendar match counts. The output is built from an explicit allow-list ("structure, never content") with async_redact_data as a safety net.

Purpose: when a calendar is empty or stale, the user (or a bug report) needs one download that says whether the feed was fetched, parsed and matched, without leaking the feed URL's token.
Output: diagnostics.py, XmltvCalendarEntity.match_count, tests/test_diagnostics.py.
</objective>
