## Phase Goal

**As a** Home Assistant user, **I want to** pinpoint specific shows with field-scoped, Unicode-safe regex plus duration and time-window filters, shape event titles and descriptions with templates, check the matches in a preview before saving, and retune any calendar instantly, **so that** each calendar shows exactly the programmes I care about, clearly titled, without re-downloading the source.

<objective>
TDD feature: precise text matching. Patterns match regardless of composed or decomposed Unicode, include and exclude each apply to fields the user chooses (title, sub-title, description, category), and a case-sensitive toggle exists (FLT-05, FLT-06). The plan also fixes the stored contract for every Phase 2 calendar setting in one pure module, xmltv/settings.py, after a decision gate on the key names (D-06).

Purpose: the core value is "exactly the programmes the user cares about". Field scope, case and Unicode are where today's matching misses or over-matches. The stored contract is written once here because every later plan (window, templates, flow) reads it.
Output: parser NFC, filter field sets and case flag, settings.py contract, pure and end-to-end tests.
</objective>
