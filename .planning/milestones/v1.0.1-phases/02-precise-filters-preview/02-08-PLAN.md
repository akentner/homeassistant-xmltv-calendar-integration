## Phase Goal

**As a** Home Assistant user, **I want to** pinpoint specific shows with field-scoped, Unicode-safe regex plus duration and time-window filters, shape event titles and descriptions with templates, check the matches in a preview before saving, and retune any calendar instantly, **so that** each calendar shows exactly the programmes I care about, clearly titled, without re-downloading the source.

<objective>
Make the advanced options behave predictably when a calendar is edited and close the phase. Editing a calendar with advanced settings pre-checks "Advanced options" and pre-fills the stored values (D-03); unchecking skips the step without resetting anything (D-03); Back keeps every entered value including the advanced ones (D-15); the form honours the case flag and refuses nested-repetition patterns (D-08); every translation placeholder is supplied. The plan ends with the full regression gate and the hands-on UAT walkthrough on ha-dev.

Purpose: FLT-11 retuning is only safe when an edit never silently drops or resets advanced settings, and the phase is only done once a human has walked the real UI.
Output: D-03 pre-check in CalendarSubentryFlow, edit/Back/form-safety tests, translation placeholder audit, UAT human-check.
</objective>
