- Follow HA's German style: informal "du", lowercase, imperative ("Gib einen Namen ein.", "Wähle mindestens ein Feld.", "Lass beide leer, um ..."). Never use "Sie". This matches HA core, where du-forms outnumber Sie-forms about 1650 to 1 in components/*/translations/de.json.
- Short labels have no trailing period. Sentences keep the punctuation of the English source.
- Keep these unchanged: placeholders in braces ({title_fields}, {default_title}, {description_fields}, {count}, {matches}, {pattern}, {error}, {template_error}), every regex example (^sky, \.de$, formel\s*1|formula\s*1, ^Tatort$, Wiederholung), /media/epg/guide.xml, allowlist_external_dirs, calendar.formel_1, http://, https://, 22:00, 02:00, all numbers and units (MiB, GiB), "Home Assistant", "XMLTV", "gzip", and the "\n\n" before {matches} in the preview description. JSON string escaping stays as in en.json: a regex backslash is written \\ in the file.
- Keep the meaning of every sentence, including the edge-case notes. The time window crossing midnight counts for its start day. Umlauts match in any Unicode form, and ß does not match ss. Searching descriptions is slower on big feeds. To is exclusive, and durations are inclusive.

| HA translation loader -> flow forms | HA overlays de.json on en.json and silently keeps English per string when placeholders differ, so a broken German string degrades without a visible error to the user. |
